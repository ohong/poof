# Unslop Design correction

The creator rejected the earlier editorial treatment. This pass applies the Ostack checklist across the landing page and collection flow.

Compared reducing decoration in the old composition with changing the content hierarchy. Chose the latter: a short task heading, one primary action, and visible sample belongings. The old layout kept product evidence below the first phone screen.

Removed Instrument Serif and italic accent headings, the ornamental sparkle, negative tracking, forced headline breaks, decorative heading punctuation, repeated directional arrows, three matching feature columns, repeated conversion sections, and sentimental filler. Neutral surfaces replace the cream treatment. DM Sans and the existing green action color remain; they support readable controls and a consistent primary action. Photographs retain their original colors and are explicitly illustrative.

Shared typography changes affect collection, object dialogs, sign-in, privacy, and error pages. Existing semantic controls, focus behavior, reduced motion, loading skeletons, errors, and reversible decisions remain. Empty states now name the state directly. The preview still has no hosted accounts or uploads. No backend or tracking changes are included.

The app has privacy information. No approved Terms of Service document is present; this remains a content need before account launch. No legal terms were invented.

Verification and comparable captures are recorded with the release artifacts. Physical-device and hosted-backend checks are outside this visual correction.
